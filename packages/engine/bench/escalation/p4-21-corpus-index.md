# P4-21 corpus index

**Status date:** 2026-09-20
**Source of truth:** [`PLAN.md`](../../../../PLAN.md) P4-21 and [`README.md`](../../../../README.md) §13.1.3 / §26 Phase 4 exit.

P4-21 requires measured, reviewable evidence for each applicable capability in the AI Justification Register. A present feature, model, or fixture does not count as a comparison by itself. `MEASURED` names the tested tier and limits; `PARTIAL` means some evidence exists but the required comparison or representative corpus is missing; `BLOCKED` names an unavailable implementation or model; `NOT APPLICABLE` follows an AI-only design or a documented absence of a model gap.

No Tier 3 entry is removed solely on these small measurements. T32 uses CC0-derived clean and controlled synthetic Lanczos/blur/noise/JPEG degradations rather than genuinely degraded photographs; the Swin2SR measurement is exploratory and not asset-cleared for product selection. T66 includes three 48×48 generated textures plus eight 32×32 CC0-derived synthetic occlusions; neither set measures real object removal or large structural fills. T27 uses four subjective target boxes and one square crop ratio. T62's accuracy smoke covers one simple, persisted generated print image per language for the original eight languages. These results support only their tested cases. Keep unmeasured capabilities visibly partial, blocked, or not applicable instead of inferring results.
