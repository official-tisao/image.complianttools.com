# T32 controlled x4 degradation benchmark

This benchmark compares the exact T32 Tier 1 engine Lanczos3 output with the registered official Real-ESRGAN x4plus ONNX conversion on the same 16 saved inputs. The test images are generated from the four individually registered CC0 sources in `../fixtures/cc0/manifest.json`.

## Reproduce

1. Ensure the Real-ESRGAN x4plus ONNX conversion exists at the registered path under the operating system temporary directory. See [`../conversion/README.md`](../conversion/README.md) for source-checkpoint verification and conversion instructions.
2. Build the engine and regenerate the fixture manifest and PNGs:

   ```sh
   pnpm --filter @complianttools/image-engine build
   node packages/engine/bench/escalation/t32/x4-degraded/prepare-fixtures.mjs
   ```

3. Run the model benchmark in the locked conversion environment:

   ```sh
   uv run --locked --project packages/engine/bench/escalation/t32/conversion \
     python packages/engine/bench/escalation/t32/x4-degraded/benchmark_real_esrgan_x4.py
   ```

The Python runner verifies the ONNX file against `docs/model-assets.json`, the exact Node-generated fixture PNG hashes/dimensions, the four-source CC0 manifest hash, and the locked ONNX Runtime/NumPy/Pillow versions. `--model`, `--output-report`, and `--artifact-dir` can override their defaults; any model path must remain under the OS temporary directory.

## Fixture construction

Each CC0 source is decoded and reduced with the engine's Lanczos3 implementation to a maximum 256 px long edge; both dimensions are rounded down to a multiple of four. Four variants are generated per source:

- clean Lanczos3 x4 reduction;
- radius-1 Gaussian-mode blur at reference size, then x4 reduction;
- clean x4 reduction, then JPEG quality 45;
- radius-1 blur, x4 reduction, deterministic per-channel grain (amount 12), then JPEG quality 45.

The saved reference is the reduced CC0 source image. The saved Tier 1 baseline is generated by the engine's `resizeRaster(..., 'lanczos3')` function from the exact same input PNG that the model receives. The reference, inputs, baseline outputs, and model outputs are lossless PNGs with their dimensions and SHA-256 values recorded in `fixtures.json` and `results.json`.

These are controlled synthetic degradations, not actual camera captures. They cover four source photographs and four specific blur/noise/JPEG recipes; they do not establish broad restoration quality. The x4 model comparison is authorized under the project owner's recorded Real-ESRGAN asset decision. The separate license-risk note in `docs/model-assets.json` remains in force.

## Current result

On these 16 pairs, Real-ESRGAN x4plus trailed Tier 1 Lanczos3 in both PSNR and SSIM for every fixture. Aggregate PSNR/SSIM was 22.9689 dB / 0.591359 for the model and 25.5075 dB / 0.635145 for Tier 1. The CPU ONNX Runtime measured 1.600 s median and 2.045 s p95 per inference. A single Chromium 151 WASM run on one recorded 64x42 fixture produced the expected 256x168 output with finite values and same-origin model/runtime requests; its 6.91 s startup-plus-first-inference time is not a steady-state estimate.

## Evaluation-only Swin2SR q4f16 candidate

The evaluation-only candidate is registered in `docs/model-assets.json` with its exact 15,249,949-byte file hash and pinned repository revision. Place the verified `model_q4f16.onnx` under the OS temporary directory at `image-complianttools-swin2sr-x4-q4f16.onnx`, then run:

```sh
uv run --locked --project packages/engine/bench/escalation/t32/conversion \
  python packages/engine/bench/escalation/t32/x4-degraded/benchmark_swin2sr_x4.py
```

The runner verifies the registered model hash and reuses the exact fixture inputs and Tier 1 outputs above. It pads the input to the model's 8-pixel window multiple and crops the 4× output before computing metrics. `results-swin2sr.json` records the full results and the `artifacts/swin2sr-q4f16/` directory contains padded model inputs and outputs. The browser smoke can be repeated on a recorded padded input with:

```sh
node scripts/onnx-runtime-browser-smoke.mjs swin2sr-x4-q4f16 \
  "$TEMP/image-complianttools-swin2sr-x4-q4f16.onnx" \
  packages/engine/bench/escalation/t32/x4-degraded/artifacts/swin2sr-q4f16/landscape-dordogne-clean-x4-swin2sr-padded-input.png
```

Across 16 controlled synthetic pairs, Swin2SR raised aggregate PSNR from 25.5075 dB to 25.6881 dB and aggregate SSIM from 0.635145 to 0.666381 versus Tier 1; PSNR was lower on clean inputs and higher in the other three degradation groups. CPU inference was 3.132 s median / 4.366 s p95. The Chromium 151 WASM fixture smoke returned the expected 192×256 output for a 64×48 padded input, with 147,456 finite values, no external requests, and 13.05 s including session startup and first inference. Treat these as evaluation results only: this small synthetic set is not representative real-camera evidence, browser speed is slow, and separate per-file licence notice/training data provenance were not established by the reviewed cards.
